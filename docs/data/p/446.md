| 문4 | PAPS 관리자와 PAPS 담임 업무 분류 내용(보이는 메뉴)은 어떻게 다르나요? |
| --- | --- |

| 문 5 | PAPS 담임권한을 받았는데도 메뉴만 보이고 학년 반이 나타나지 않을 때는 어떻게 해야 하나요? (NEIS 담당자 문제) |
| --- | --- |
| 답 | NEIS담당자가 개인별 권한 등록 시스템 자료 권한에서 반별 권한을 주지 않았기 때문에 학년 반이 나타나지 않는 것이므로 반별 권한을 부여 받으면 됩니다. |

| 문 6 | 정시와 수시의 다른 점이 무엇인가요? |
| --- | --- |
| 답 | 교무업무시스템 PAPS의 「회차등록」은 정시(법령에 의한 측정)와 수시(학교자체시행)로 구분되어 있으며, 정시의 경우 년1회로 제한되어 있으며, 수시측정은 수시등록이 가능하며 정시 회차 이외의 수시 회차에(수시1, 수시2...)에 등록해야합니다.<br>또한, 정시에 측정자료가 입력되어야지만 건강기록부내에 기입이 되며 수시에 측정한 자료는 건강기록부에 기입되어지지 않습니다. |

| 문 7 | 측정 회차 일자와 실제 측정일자가 일치하지 않을 때는 어떻게 해야 하나요? |
| --- | --- |
| 답 | 측정회차의 일자는 하루 이상 설정이 불가합니다.<br>또한, 평가도 회차 단위로 이루어지기 때문에 회차를 나누어 설정하시면 안됩니다.<br>그러므로, 측정회차의 일자는 대표 측정일을 정하여 입력하시기 바랍니다. |

| 문 8 | PAPS 측정은 언제 해야 하며 결과는 언제까지 제공해야하나요? |
| --- | --- |
| 답 | PAPS 측정을 학기초에 측정하는 것으로 측정 이후 1개월내에 학생, 학부모에게 결과를 제공해야합니다. ※ 학교건강검사규칙(부령) 참조 |

| 문 9 | 수시 회차 삭제하고자 할 때 어떻게 해야 하나요? |
| --- | --- |
| 답 | 수시 측정 회차를 먼저 측정마감취소-입력마감취소를 해주신 이후 [측정 회차 관리]에서 수시 회차 선택 후 삭제하시면 측정결과에 대한 자료가 삭제되어집니다. |

| 문 10 | 측정종목을 수정해야하는데 활성화 되지 않을 때 어떻게 해야 하나요? |
| --- | --- |
| 답 | 측정 학년 모두 측정마감 취소, 입력마감 취소를 하게 되면 측정 종목을 수정할 수 있게 활성화가 됩니다.<br>※ 측정 종목 변경시 이전의 입력된 데이터 자료들이 영구삭제 되므로 일괄입력에서 모든 데이터를 백업 받아 놓아야 합니다. |

| 문 11 | 필수평가 등록 후 선택평가를 추가로 하고자 할 때 어떤 방법이 있나요? |
| --- | --- |
| 답 | 측정 회차에 수시를 생성하여 선택평가를 추가로 입력할 수 있지만 수시는 건강기록부 등록과, PAPS 통계생성(교육청보고용)이 되지 않으므로 정시에 추가로 입력하시면 됩니다.<br>측정종목선택에서 필수평가만 선택한 경우 필수평가에 대한 자료를 먼저 백업 받으시고, 측정 종목 선택에서 선택평가를 추가 선택하여 저장 후 필수평가, 선택평가의 결과를 등록하면 됩니다.<br>※ 측정 종목 변경시 이전의 입력된 데이터 자료들이 영구삭제 됨 |

| 문 12 | 필수평가의 심폐지구력종목과 선택평가의 심폐지구력 결과입력은 어떻게 하나요? |
| --- | --- |
| 답 | 필수평가의 심폐지구력 측정종목과 선택평가의 심폐지구력정밀평가의 종목은 동일하게 자동 적용됨으로 심폐지구력정밀평가 측정시 심폐지구력 동시측정 효과(종목을 달리 하지 않음)를 내서 필수평가의 심폐지구력은 결과를 입력할 수 있도록 활성화가 되지 않습니다. 그러므로 선택평가의 심폐지구력 정밀평가만 입력하면 필수평가는 자동 입력됩니다. |

문 13

필수평가의 체지방과 선택평가의 비만평가의 차이점은 무엇 인가요?

답

필수평가 체지방의 종목은 체질량지수(BMI), 체지방량(%FAT)이며, 선택평가 비만평가의 종목은 체지방량(%FAT)으로만 가능합니다.

필수평가의 체질량지수(BMI)는 키와 체중을 통해 결과가 제공되며, 비만평가의 체지방량(%FAT)은 체성분분석기를 통해 결과가 제공되어집니다.

※ 체지량지수(BMI)로 선택평가인 비만평가가 불가함

※ 필수평가-체지방-체질량지수(BMI) 계산식 : 체중(kg)/키(m)²

※ 선택평가-체지방-체지방량(%FAT) : 체성분 분석기를 통한 결과제공

문 18

일괄입력메뉴에서 엑셀파일 업로드시 1라인에 오류가 나타날 때 어떻게 해야 하나요?

답

입력자료의 오류시 이런 현상이 발생하는데 1라인에 해당하는 것은 디폴트로 정해져있는 학년, 반, 번호, 측정종목데이터 등 을 안내하는 라인입니다.

일괄입력 메뉴에서 해당종목의 자료내리기를 한 후 올리려고 했던 자료와 다른 점이 있는지 비교해보아야 합니다.

올리려고 했던 파일과 자료내리기를 한 파일이 동일하다면 학생정보와 측정결과만 NEIS에서 받은 파일에 붙여넣기를 해서 다시 업로드를 해보면 됩니다.

※ 간혹 엑셀 2003버전일 경우 파일형태가 동일해도 오류가 생기는 경우가 있으므로 PAPS 자료는 엑셀 2007버전을 권장함

문 28

체력우려(4,5등급) 학생의 관리는 의무적인가요?

답

학생건강검사규칙(부령) 제10조1항에 의하여, 검사 결과에 따라 소속 학생에 대하여 건강상담, 예방조치, 체력증진 등 대책을 강구해야하므로, 측정이후 결과의 적절한 후속조치를 해야합니다.

※ 학교건강검사규칙(부령) 제10조 (건강검사 결과의 조치) ① 학교의 장은 그 학교가 소재하는 지역 보건기관, 체육단체 및 대학 등의 협조를 얻어 건강검사의 결과에 따라 소속 학생 및 교직원에 대하여 건강상담, 예방조치, 체력증진 등 그 밖에 적절한 보호 또는 양호의 대책을 강구하여야 한다.

| 문 29 | 체력우려(4,5등급) 학생의 관리를 위한 수업모형은 제공되나요? |
| --- | --- |
| 답 | 측정이후 신체활동처방 제공시 각 체력등급에 맞는 자료가 제공됨으로, 체력우려(4,5등급) 학생의 관리를 위한 체육수업모형, 방과후활동모형, 가정활동모형 등을 활용할 수 있습니다. |

| 문 30 | 입력마감과 측정마감의 차이가 무엇인가요? |
| --- | --- |
| 답 | 입력마감은 반별 담임선생님의 권한으로 반별 측정 결과 입력을 끝낸 뒤 마감 처리를 하는 것이고 측정마감은 반별 입력마감 후 PAPS담당자가 측정 마감 처리를 하는 것입니다. |

| 문 31 | 측정마감후의 기안문 작성과 PAPS 통계의 기안문 작성 두 가지가 있는데 어떤 기안문을 작성해야 하나요? |
| --- | --- |
| 답 | 측정마감의 기안문 작성은 측정이 완료되었다는 것을 학교 내부적으로 하는 결재이며, PAPS 통계의 기안문 작성은 교육청 보고를 위한 기안문 작성으로 측정결과입력 후 PAPS 통계가 생성되면 결재하시는 것입니다. |

| 문 32 | 교육청에 보고 하는 절차가 어떻게 되나요? |
| --- | --- |
| 답 | 교육청 통계 보고 절차는 각 반별 입력마감[측정결과입력-입력마감] → 학년 별 측정마감[측정종목관리-측정마감] → PAPS 통계생성[통계 및 현황-PAPS통계]→ 기안문 작성[통계 및 현황-PAPS통계]→ 내부 결재 완료→ 교육청보고[통계 및 현황-PAPS통계]로 되어집니다. |

| 문 33 | 기안문을 취소하려고 할 때 어떤 절차를 거쳐야 하나요? |
| --- | --- |
| 답 | 기안문 상신 결재가 완료되지 않았다면 담당자에게 결재 현황판에서 기안문 삭제 요청을 하면 되고, 결재 후라면 결재자에게 기안문 결재 취소 요청을 하면 됩니다. |

| 문 34 | 측정마감 이후 데이터를 수정해야 할 때 어떤 방법이 있나요? |
| --- | --- |
| 답 | 측정마감 취소, 입력마감 취소를 하면 데이터 수정이 가능합니다. |

| 문 35 | 교육청 전송이후 데이터를 수정해야 할 때 어떤 방법이 있나요? |
| --- | --- |
| 답 | 교육청에서 통계마감을 하지 않았을 경우 : PAPS 관련한 기안문 삭제(NEIS 담당자 권한) – [측정마감취소] - [입력마감취소] - 데이터 수정 - [입력마감] - [측정마감] - [통계생성] – [기안문작성] - [교육청보고]를 하시면 자동으로 교육청결과가 재전송되어집니다.<br>교육청에서 통계마감을 하였을 경우 : 학교 내부적으로는 결과가 수정되지만 교육청보고는 되지 않습니다(단, 교육청에서 마감취소 후 수정 가능함). |

| 문 36 | 측정 결과 조회 방법에는 어떤 것들이 있나요? |
| --- | --- |
| 답 | 평가결과 조회에서 학급별, 종별, 개인별 조회가 가능하고 일괄입력 자료내리기에서 또한 가능합니다. |

| 문 37 | 측정결과 제공 방법에는 어떤 것들이 있나요? |
| --- | --- |
| 답 | www.parents.go.kr 또는 www.neis.go.kr 로 접속하셔서 학부모 서비스에서 측정 결과를 확인할 수 있으며, 또는 각반 담임선생님께서 결과지를 출력해서 우편으로 보내는 방법이 있습니다. |

| 문 38 | PAPS 지수조회에서 각 지수에 명수가 표기 되지 않을 때는 결과 입력에 문제가 있는 건가요? |
| --- | --- |
| 답 | 아닙니다. 예를 들어 PAPS 체력지수의 경우 체력 1등급 학생수를 정시 필수 참여 수로 나누는데 이때 1등급 학생수가 존재하지 않는다면 해당하는 학생이 없는 결과가 초래되기 때문에 각 지수에 대한 명수가 표기 되지 않을 수 있습니다. |

| 문 39 | 측정결과 상위 5% 조회하는 방법이 무엇인가요? |
| --- | --- |
| 답 | 평가항목별 백분위조회 메뉴에 항목을 선택하여 건강체력이라는 조건으로 조회하면 종합결과에 대한 조회가 가능합니다.<br>또한 PAPS에는 상위5%가 최소단위로 3%조회를 하시려면 5% 학생 내에서 자료를 산출하셔야 합니다.<br>높은 학생 순서대로 조회됩니다. |

| 문 40 | 실제 학생 수와 통계의 수치가 일치하지 않을 때는 결과입력이<br>잘못된 건가요? |
| --- | --- |
| 답 | 전입생에 대한 자료를 그대로 반영할 경우 전입생에 대한 통계는 이전의 학교에서 집계됩니다. 또한, 전학생에 대한 부분도 확인하여 통계의 수치를 확인하기 바랍니다. |

| 문 41 | 전입생, 전출생 통계처리 방법은 어떻게 되나요? |
| --- | --- |
| 답 | 전입생 자료를 그대로 반영할 경우 전입생 통계처리는 이전의 학교에서 반영되며, 전출생의 경우 전입학교에서 재 측정시에는 전출학교 통계에 반영이 되지 않고 전입학교 통계에 반영이 됩니다. |

| 문 42 | 미 측정 학생 통계처리 방법은 어떻게 되나요? |
| --- | --- |
| 답 | 미 측정 학생의 경우는 누락학생에만 조회되며 학교 결과 통계에는 반영 되지 않습니다. |

| 문 43 | PAPS 데이터 보건자료 연계 방법은 무엇이 있나요? |
| --- | --- |
| 답 | 입력마감 측정마감 후에 측정결과입력에서 신체 능력등록에서 학년 반 조회후 PAPS 자료 불러오기를 하면 건강기록부상의 등록이 됩니다. |

| 문 44 | 보건 신체능력검사에 체지방율이 나타나지 않을 때는 데이터 입력 오류인가요? |
| --- | --- |
| 답 | 보건-신체능력검사의 PAPS 자료 불러오기는 정시측정한 자료만 연동이 됩니다.<br>필수평가의 체지방은 체질량지수(BMI)로 키와 체중만 있으면 결과가 제공되며 선택평가의 체지방은 체지방율(%FAT)로 체성분측정기로 측정하여야 결과가 제공됩니다.<br>보건-신체능력검사의 체지방율(%fat)은 선택평가의 비만평가를 측정하였을 경우만 나타나며 필수평가에서 측정한 체지방(BMI)은 보건-신체발달검사에서 조회가 됩니다. |

| 문 45 | 보건의 신체능력검사의 메뉴가 나타나지 않을 때 어떻게 해야<br>하나요? |
| --- | --- |
| 답 | 보건 메뉴의 신체능력검사가 보이지 않을 경우는 PAPS의 권한만 부여되고 보건의 권한이 부여되지 않았기 때문입니다.<br>NEIS 담당자에게 요청하시어 보건에 대한 권한을 부여받으시면 됩니다. |

| 문 46 | 통계생성이 되지 않을 때는 확인 절차는 어떻게 되나요? |
| --- | --- |
| 답 | 입력마감 측정마감 확인 후 정시 회차로 입력을 하였는지 확인해야 합니다. 만약 수시로 입력되어 있다면 통계생성이 되지 않습니다. 일반 통계는 정시, 수시 모두 확인 가능하지만 교육청에 전송하는 통계는 정시만 나타납니다. |

| 문 47 | 학생서비스 이용 방법에는 어떤 것이 있나요? |
| --- | --- |
| 답 | 초등학생의 경우 www.parents.go.kr 또는 www.neis.go.kr에 학부모의 공인 인증서로 로그인 후 학생서비스를 이용할 수 있습니다.<br>중학생 이상은 학생공인증서를 발급받아 이용할 수 있습니다. |

| 문 48 | 학부모 서비스 이용은 어떻게 하나요? |
| --- | --- |
| 답 | 학생건강체력평가시스템은 기존의 NEIS(교육정보시스템) 내에 구축하고 교사뿐만 아니라 학생, 학부모 서비스를 강화하여 구축하였으며, On-Line 시스템 접속 시 학생과 학부모 모두 학부모 개인별 인증서로 접속합니다.<br>※ 초등학교의 경우 인증서 분실 등 보안 문제로 학부모용 인증서 사용 |
