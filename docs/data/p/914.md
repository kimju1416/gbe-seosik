1. 초임호봉 개요
1) 초임호봉 산정을 위한 개요를 등록/수정/삭제

2. 온라인채용시스템 경력합산신청서 연계
1) 임용시험별 온라인채용시스템 경력합산신청서 연계하여, 데이터 가져오기

3. 초임호봉산정 및 결과조회
  - 1) 초임호봉자동산정
  - 2) 초임호봉산정결과 조회
4. 임용발령자료생성
1) 산정결과를 기준으로 개요 마감 및 임용발령자료생성

5. 초임호봉대상자 관리
  - 1) “신규임용후보자”를 초임호봉대상자로 차수별 일괄생성
  - 2) 전임경력, 군경력, 대학학력, 대학원학력, 교원자격증, 가산정보
등록/수정/삭제

6. 전력조회요청기안 및 등록
1) 전임경력, 군경력에 대한 자료를 업체별로 기안문 작성

7. 평가심의자료총괄표 및 대상자별호봉획정표
1) 평가심의자료총괄표/대상자별호봉획정표 조회 및 출력

# 호봉정정 대상자관리

- - 군경력신청정보

주요 기능 상세
**1. 군경력 등록/수정/삭제**
1) 호봉정정 대상자 선택 후 군경력신청정보 탭을 선택 또는
“조회” 클릭하면 군경력 목록이 조회된다.
2) “군경력가져오기” 클릭하면 팝업이 뜨고, 인사에 등록된
군경력이 조회되고 선택 후 저장한다
3) “추가＂클릭 후 필수항목을 입력하고 “저장＂한다.
4) 잘못 입력 된 정보를 수정 후 “저장”하거나 “삭제＂한다.
이때, 신청자가 입력한 정보는 삭제 불가하다.
5) 군경력제외기간의 “선택＂클릭하면 군경력기간에
제외되는 기간을 입력하는 팝업이 뜨고 입력 후 저장한다.
6) 증빙첨부의 “첨부“ 클릭하면 첨부파일을 등록하는
팝업이 뜨고 파일을 저장한다
7) 군경력제외기간 계산된 기간이 아니라면 수기 입력을
위해 체크 후 해당 년/월/일을 직접입력한다.
8) 군경력인정기간 계산된 기간이 아니라면 수기 입력을
위해 체크 후 해당 년/월/일을 직접 입력한다.
9) 입력한 경력에 인정률을 확인 후 입력한다.
10) 군경력을 호봉산정에 인정한다면 인정여부를 체크한다.
Tip 1. 군경력 정보 입력은 군경력가져오기 -> 추가 순으로 입력하는 것이 좋다.
Tip 2. 군경력가져오기 , 군경력제외기간, 첨부파일의 팝업에서 저장을 하더라도 호출한 화면에서 반드시 저장해야 정보가 저장된다

# 호봉정정 산정 및

# 결과조회

주요 기능 상세 1. 호봉정정 산정 및 결과 조회 1) 조회조건에 해당 내용을 입력 후 “조회” 버튼 클릭 시 개요의 대상자 목록이 조회된다. 2) “호봉정정자동산정” 클릭하여 호봉정정대상자의 정보에 따라 호봉산정을 한다. 3) 호봉정정대상자를 선택 후 대상자의 산정된 상세 정보를 전임경력정보, 군경력정보, 대학학력정보, 대학원학력정보, 교원자격증정보, 임용정보, 가산정보, 징계정보 탭으로 조회된다. 4) 호봉정정대상자를 선택 후 호봉정정상세에 산정된 상세 결과가 조회된다 Tip 1. 호봉정정대상자의 진행상태가 승인이고, 확인여부가 체크되어야 목록에서 확인 할 수 있다.
