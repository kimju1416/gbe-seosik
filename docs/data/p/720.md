〔이미지〕

학교규칙(학생생활규정) 제·개정 절차

| 처리 절차 | 업무 내용 |
| --- | --- |
|  |  |
| ① 제·개정 위원회 구성 | ▪ 학생, 교원, 학부모(보호자)로 구성(필요시 전문가로 구성)<br>▪학생위원 수가 전체 위원의 1/3 이상 구성 |
|  | ⇩ |
| ② 제·개정안 발의 | ▪ 학교 구성원, 학교규칙 제·개정 위원회, 학생회, 교직원회, 학부모회 등의 발의 |
|  | ⇩ |
| ③ 학교공동체 의견 수렴 | ▪ 발의안에 대한 문구와 적정성 검토<br>▪ 학교규칙 제·개정 위원회를 통해 다양한 방법으로 학교 구성원[학생, 학부모 (보호자), 교원]의 의견 수렴<br>▪ 발의안 확정 |
|  | ⇩ |
| ④ 제·개정 심의안 확정 | ▪ 제·개정 절차 위원회에서 발의안에 대한 적정성 검토 후 제·개정 심의안 확정 |
|  | ⇩ |
| ⑤ 학교운영의윈회 심의 | ▪ 학교운영위원회 심의 과정에 학생 대표 참석 및 의견 개진 기회 부여<br>▪ 학교운영위원회 심의 후 제·개정안 확정 |
|  | ⇩ |
| ⑥ 학교장 결재 | ▪ 학교운영위원회 심의 결과인 제·개정안 승인 |
|  | ⇩ |
| ⑦ 공포 및 적용 | ▪ 학교 구성원들이 제·개정된 규정을 알 수 있도록 학교 게시판, 홈페이지, 가정통신문 등 통해 공고<br>▪ 학교 홈페이지에서 학생과 학부모(보호자) 등이 알기 쉽게 별도의 메뉴를 활용하여 공지 |
|  | ⇩ |
| ⑧ 제·개정 규정 안내 | ▪ 학교공동체 대상 제·개정 규정 안내 |
|  | ⇩ |
| ⑨ 적용 및 환류 | ▪ 학생생활규정 운영 결과 평가·환류<br>▪ 개정이 필요한 사항에 대한 의견 수렴·분석 |
