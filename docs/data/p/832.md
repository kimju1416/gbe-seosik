▶ 학생서비스 메인화면에서 오른쪽 상단의‘회원가입’버튼 선택합니다.
▶ 회원가입 단계 : 이용약관동의 → 본인확인 → 회원정보입력 → 학생서비스 신청항목
입력 → 회원가입 완료

◦ 회원가입 절차

- - 학생서비스 메인화면 → ‘회원가입’버튼 선택 → 회원유형 선택(만14세 미만 학생회원,
만14세 이상 학생회원) → 약관동의 → 본인확인(I-PIN, 휴대폰 인증) → 회원정보입력(ID,

PW 등) → 학생서비스 신청항목 입력(학교, 신청일자 등) → 선택사항 입력(이메일, SMS

수신여부 등) → 회원가입완료 → 인증서발급 → 인증서 등록

◦ 가입완료 후 인증서를 발급(약관동의 및 본인확인)받고 학적확인 이후 인증서를 등록합니다.

◦ 학생서비스의 생활, 건강, 성적 등의 정보를 열람하기 위해서는 회원 가입 후 인증서를

등록하고, 등록된 인증서로 로그인하여 이용합니다.
