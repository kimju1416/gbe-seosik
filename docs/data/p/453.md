# 거북목 증후군을 아시나요?

‘거북’이라는 단어에서 떠오르듯이 거북목 증후군이란 오랜 시간 컴퓨터 등의 스크린을 내려다봄으로 머리가 앞으로 향한 꾸부정한 자세를 말합니다. 인터넷 사용자들이 꾸준히 늘어나면서 인터넷 중독 환자와 함께 거북목 증후군 환자의 수가 꾸준히 늘고 있습니다. 거북목증후군은 머리나 어깨, 목에 통증을 느낄 뿐 아니라 쉽게 피로해지고 집중력을 떨어뜨려 학습 능력을 저하시키고, 어린이 키 성장에도 영향을 주고 있습니다. 아래 예방법을 익혀 실천합시다.
