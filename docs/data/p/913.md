### 기본메뉴 > 퇴직 > 명예퇴직신청

주요 기능 상세
**1. 명예퇴직 신청자의 인적사항 및 근무 사항이 자동**
조회되고, 현재 일자 기준으로 명예퇴직 공고기간 일 경우 명예퇴직 신청이 가능한 상태가 된다.
(각 버튼 및 선택사항 활성화)
**2. 명예퇴직 공고 개요는 ‘공고문조회’ 버튼으로**
공고문조회 팝업을 호출하여 확인한다.
**3. 상단의 [신상정보]와, [비위형벌사항]을 입력 또는**
선택한다. [명예퇴직수당 산출 정보]에 명예퇴직 신청자의 명예퇴직 산출 내역을 확인하고 장해등급,
특별승진신청여부, 사전 신청 여부에 해당하는 경우 해당 내용을 선택한다.
첨부해야 할 서류가 존재하는 경우 제출 서류에 파일을 추가한다.
입력사항을 모두 입력 후 ‘저장’버튼을 클릭하여 해당 정보를 임시저장한다.
**4. 특별승진신청에 신청을 선택한 경우**
‘특별승진공적조서작성’ 버튼으로 공적조서 작성화면을 호출하여 해당 공적조서를 작성한다.
**5. ‘명예퇴직원작성‘버튼으로 명예퇴직원 작성 화면을**
호출하여 명예퇴직원을 작성한다.
명예퇴직원 작성이 완료되면 ‘신청’버튼을 클릭하여 소속기관에 제출한다.
명예퇴직 신청 현황은 ‘진행현황조회’버튼으로 진행상태 조회 팝업을 호출하여 확인한다. (신청 전에는 조회 불가)

‘산출근거조회‘ 또는 ‘명예퇴직수당지급신청서’ 버튼을 클 릭하여 확인 가능
Tip 2. 신청 이후 ‘신청취소’가 가능하며, 저장 및 삭제는 불
  가. 삭제는 신청취소 이후 가능

'승인요청'버튼을 클릭하여 에듀파인 결재기안 팝업을 호출하여 결재기안을 상신한다.
**6. ‘회신결과업로드’버튼을 클릭하고**
내외부기관으로부터 수신한 결격자 회신결과 엑셀 파일을 업로드하여 일괄등록한다.
Tip 1. 회신결과업로드는 대상자명단생성으로 다운로드된 엑셀파일을 사용한다.
엑셀 파일 양식을 변경한 경우 업로드가 불가하다.
회신결과(Y/N), 결격여부(Y/N), 결격사유만 입력 후 업로드한다.
