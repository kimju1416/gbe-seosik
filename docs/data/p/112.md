# 등교 중지 안내서

반 이름:

안녕하세요? 가정에 건강과 행복이 함께 하길 기원합니다.

위 유아는 감염병(예시 : 수두)에 감염되었거나 감염이 의심되어 다른 유아의 감염을 예방하기 위하여 등교중지를 권고하오니, 뒷면 진료확인서에서 의사가 적시한 기간 동안 등교중지 시키고 아래의 가정에서 지켜야 할 사항을 준수하여 주시기 바랍니다.

등교 중지 기간 동안 가정에서 지켜야 할 사항
1. 완치될 때까지 가정 또는 병의원에서 격리치료를 받습니다. 2. 유치원 밖 교육시설(학원, 교습소, 개인과외 등) 이용과정에서 타 유아 감염이 초래되지 않도록 가정 내 생활지도를 철저히 하여야 합니다. 3. 가족 간에도 감염 우려가 있으므로 가정 내에서도 위생관리를 철저히 합니다. 4. 완쾌 후 등교할 때는 선생님께 진료확인서, 의사소견서, 진단서, 처방전 중 1부를 제출하여 주시기 바랍니다.

※ 등교 중지 기간까지 완치되지 않은 경우 전염력이 없다는 의사의 진단일까지 기간을 연장합니다.

※ 등교 중지 기간은 결석으로 처리되지 않습니다.
