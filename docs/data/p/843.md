# 학교 개인정보처리방침 관리 매뉴얼

홈페이지 관리자모드를 통해서 개인정보처리방침 관리 서비스를 제공합니다.

홈페이지 관리자모드는 학교 관리자 권한을 부여받은 사용자만 접속이 가능합니다.

관리권한 : 학교 관리자 권한

본인이 소속되어있는 홈페이지로 접속하여 상단의 “로그인” 후 관리자모드를 클릭하여 관리자 모드로 접속합니다.

[ 메뉴/게시판/팝업 → 하단메뉴관리 ] 로 접속합니다.

### 제4조(개인정보의 위탁)

〔이미지〕

◦ 위탁사항 게시판을 연결 할 수 있으며 선택한 게시판에서 위탁사항을 관리 할 수 있습니다.

① 위탁사항 게시판이 없을 경우 먼저 메뉴추가하기를 합니다.

※ 메뉴 위치는 학교에서 선정

1. 메뉴명: 개인정보 위탁계약 안내

2. 메뉴형태: 게시판

3. 게시판 선택: 신규게시판

4. 게시판종류 선택: 개인정보 처리방침 위탁 게시판

5. 게시판 스킨 선택: 회색, 파랑색, 올리브, 오렌지, 핑크 중 마음에 드는 스킨으로 선택

6. 저장

② “위탁사항 게시판 메뉴 링크”에 개인정보 위탁계약 안내를 선택합니다.

### 제10조(개인정보 처리방침의 변경)

〔이미지〕

◦ 개인정보 처리방침 이력 게시판을 연결 할 수 있으며 선택한 게시판에서 개인정보처리방침 이력을 관리 할 수 있습니다.

① 이력 게시판이 없을 경우 먼저 메뉴추가하기를 합니다.

※ 메뉴 위치는 학교에서 선정

1. 메뉴명: 개인정보 처리방침 이력

2. 메뉴형태: 게시판

3. 게시판 선택: 신규게시판

4. 게시판종류 선택: 이전 개인정보 처리방침 게시판

5. 게시판 스킨 선택: 회색, 파랑색, 올리브, 오렌지, 핑크 중 마음에 드는 스킨으로 선택

6. 저장

② “개인정보처리방침 이력관리 게시판명”에 개인정보 처리방침 이력을 선택합니다.

③ 이전 개인정보처리방침 첨부파일 보기 항목에서 “보기”를 선택 할 경우 이전 개인정보처리방침 파일을 
 링크 현황을 하단에 계속 디스플레이 합니다.

※ “감추기”를 선택 할 경우 이전 처리방침을 다운로드 받아 “이전 개인정보 처리방침 게시판”으로 추가 등록하여야 합니다.

변경 내용의 적용

〔이미지〕

◦ 버튼을 클릭하여 지금까지 변경한 개인정보처리방침 내용을 일괄수정할 수 있습니다.

〔이미지〕

수정한 내용의 이력 게시판 등록

〔이미지〕

◦ “확인” 버튼을 누르면 이전 자료가 “이전 개인정보 처리방침 게시판”에 자동으로 등록 됩니다.

※ 반드시 이력 게시판에 등록하여야 하는 사항 : 제2조 개인정보종합지원시스템에 등록한 개인정보 파일 목록이 변경되는 경우, 제9조 개인정보 보호책임자의 내용이 변경되는 경우

“취소” 버튼을 누르면 이력 게시판에는 등록되지 않고 내용만 수정이 됩니다..
