□ 개인정보 점검프로그램 실행 및 청소 방법

1. 점검 프로그램(Privacy-i) 실행

▶ 화면 오른쪽 하단에 숨겨진 아이콘 표시()를 클릭하여 프로그램 아이콘() 더블클릭 〔이미지〕 〔이미지〕 〔이미지〕
※ Privacy-i 아이콘()이 보이지 않을 경우: 예산정보과-12409(2024. 7. 19.) 〔이미지〕 「[안내] 개인정보 파일 암호화 프로그램 설치」 공문을 참고하여 프로그램 설치

2. 검사 실행

▶ 프로그램 실행 → 기본 검사 클릭(검사는 30분 이상 소요됨)
〔이미지〕

3. 검사 결과 확인

▶ 검출 파일 개수 확인
〔이미지〕

4. 검출된 파일 확인

▶ 보존이 필요한 파일: 암호화, 보존 필요 없는 파일: 완전 삭제
※ 파일명을 더블클릭하면 해당 파일이 열림
〔이미지〕

5. 프로그램 재실행

▶ 프로그램 재실행 → 보유(보존) 파일 개수 확인
〔이미지〕
