# 계약제 교원 자료전송

이전 근무 기관에서 등록한 자료를 현재 근무 기관으로 전송 받아 입력 가능

계약제교원의 자료 전송 범위(2019.2.기능개선)

개인신상, 병역, 외국어해득, 연수, 외국시찰 수학, 포상/서훈, 징계/형별, 연구실적, 적

성검사, 비고, 경력, 승급기록, 보충기재란, 자격취득, 가산점의 자료

● 신규 채용한 계약제교원이 업무포털 접속이 안되요?
1) 인사기록 등록 여부 확인
2) 인증서 발급 여부 확인
3) 업무포털 사용자 등록 확인
- 도내(경북)에서 근무 한 경력이 없는 경우: 사용자등록 후 로그인
- 도내(경북)에서 근무 한 경력이 있는 경우: 인증서변경 후 로그인

● 호봉재획정 작업을 해서 시행처리까지 했는데 근무연수를 잘못 입력했습니다.
수정은 어떻게 하나요?
=> 시행한 기안문은 삭제 할수 없으며, 수정은 상위기관에 문의 후 처리하여야 합니다.(고등학교→본청, 중학교→지역청)
● 9월 1일자 휴직 교사인데 휴직 처리 시행을 미리하여 휴직처리가 되었습니다.
업무처리가 안되는데 재직상태로 어떻게 돌리나요?
=> 모든 임용발령처리는 시행과 동시에 인사기록에 반영됩니다. 이미 시행 한 건은 학교에서 되돌릴 수 없으니 상위기관에 문의하여 처리하여야 합니다.
=> 재직상태로 돌아오면 권한은 다시 부여하여야 합니다.

● 퇴직한 계약제교원의 경력증명서를 발급하면 근무기간이 나타나지 않아요?
=> 경력증명서의 경력은 인사기록 경력탭에 있는 자료들입니다. 기간제 교원 인사기록을 조회하셔서 해당 경력 자료가 있는지 확인하신 후 없다면 입력해주시기 바랍니다.
● 개인정보 변경승인 화면에 들어가면 권한이 없다고 나옵니다?
=> 인사기록 ⇨ 개인정보변경관리 ⇨ 개인정보변경승인자관리에서 인사담당자(교감)
이름으로 조회 후 항목체크가 되어있는 확인해 봅니다.
