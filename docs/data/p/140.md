# Ⅰ. 개요

### 1. 근거

❍ 개인정보 보호법 및 같은 법 시행령

❍ 개인정보보호위원회 표준 개인정보 보호지침

❍ 교육부 개인정보 보호지침

### 2. 추진 배경

❍ 다량의 학생·학부모 개인정보 보유 기관에 대한 개인정보 강화 필요성 증대

❍ 개인정보 의식 및 역량 부족에 따른 개인정보 오남용 등 법 위반사례 발생

### 3. 추진 목표

❍ 개인정보 오·남용 및 유·노출 방지를 통해 정보주체의 권익보장

❍ 관련 법령 기반의 안전하고 신뢰받는 개인정보보호 환경 구축

❍ 개인정보 유출 예방 활동 강화 및 개인정보보호 의식 고취

## 3. 세부 추진 내용

### 개인정보 처리 이행 철저

❍ 개인정보의 수집·이용

- 정보주체의 동의에 의한 개인정보 수집

∘ 수집목적, 수집항목, 보유 및 이용기간, 거부권 안내

∘ 목적에 필요한 최소한의 개인정보 수집 원칙 준수

- 고유식별정보, 민감정보는 별도 동의 취득

- 주민등록번호는 수집 시에는 관련 법령 근거 제시

❍ 개인정보 제3자 제공 및 목적 외 이용·제공

- 제공 제한: 정보주체의 동의 및 법률에 규정이 있는 경우

- 제공 사실 공지 ※ 처리 절차는 [별첨2] 참고

∘ 제공받는 자, 이용목적, 제공 항목, 보유 및 이용기간

- 개인정보 목적 외 이용·제공할 경우 대장 기록·관리

❍ 개인정보 처리 업무 위탁

- 개인정보에 대한 위탁 계약을 체결하는 경우 사업담당자는 표준 위탁계약서를 활용하여 계약서 체결

- 수탁자 교육 및 관리·감독 철저(연1회 이상)

- 사업 종료 시 개인정보 파기 확인

### 개인정보파일 정비

### 개인정보 보호 교육

❍ 개인정보 보호책임자

- 교육목표: 개인정보의 중요성을 인식하고 대책 마련에 적극적이며, 이에 대응할 수 있는 능력 배양

- 교육내용: 개인정보의 개념, 개인정보보호의 중요성과 필요성, 개인정보 보호책임자의 역할과 책임, 개인정보 라이프사이클 이해 등

- 교육방법: 도교육청 일괄연수, 권역별 순회연수 및 정보보호 교육 센터 연수 활용

- 교육일정: 학년초(일괄연수), 순회연수(분기별)

※ 개인정보 보호책임자는 연1회 이상 교육 이수 필수

❍ 개인정보 보호 업무담당자

- 교육목표: 개인정보의 중요성을 인식하고 개인정보의 안전성 확보를 위해 필요한 기술적/관리적 보호조치에 대해 습득

- 교육내용: 개인정보 개념, 개인정보보호법 이해, 개인정보 라이프사이클, 유출사례 분석, 안전성 확보조치 이해 등

- 교육방법: 교육지원청 일괄연수 및 도교육청 권역별 순회연수 활용

- 교육일정: 학년초(일괄연수), 순회연수(분기별)

※ 개인정보 보호 총괄 업무담당자는 학년초 일괄연수는 필수 참석하며, 순회연수는 선택 이수함

❍ 개인정보 취급자

- 교육목표: 개인정보의 중요성을 인식하고 개인정보보호 핵심 적용 및 개인정보 사례를 통한 개념 습득, 학교 내 반드시 적용해야 할 개인정보보호 핵심 요소 학습

- 교육내용: 개인정보보호 개요 이해, 개인정보보호의 중요성, 개인정보보호 법률의 이해, 처리단계별 보호기준, 목적 외 이용 및 제3자 제공 절차서, 개인정보 유출사고 대응 매뉴얼

- 교육방법: 자체 교육(전 직원 70%이상 참석)

- 교육일정: 4월

❍ 개인정보 수탁자 교육

- 교육목표: 개인정보 보호법을 이해하고 외부 용역업체의 중요자료 유출 및 보안위규 사고 방지에 대한 인식 제고

- 교육내용: 개인정보보호 준용 사항, 개인정보 처리 및 안전성 확보 조치 등

- 교육방법

∘ 학교 방문 수탁업체: 교육 자료를 활용한 사업담당자 직접 교육 실시

∘ 위탁사업을 수탁기관에서 하는 경우: 현장 방문 점검 및 교육 실시

- 교육일정: 계약 완료 후 바로 실시 ※ 수탁 업체별 연 1회 이상 반드시 실시

## 개인정보 목적 외 이용 및 제3자 제공 처리 절차

| --- | --- | --- |
|  |  |  |
| 1. 제공 사유 발생 | 개인정보취급자 | - 개인정보 제공 요청 문서 접수<br>- 개인정보 제공 사유 발생 시 |
| ↓ |  |  |
| 2. 법적 근거 검토 | 개인정보취급자 | - 목적 외 이용‧제3자 제공이 가능한 경우에는 해당되는지 법적근거 검토 |
| ↓ |  |  |
| 3. 동의절차 진행 | 개인정보취급자 | - 법적근거가 없는 경우 정보주체로부터 별도의 동의를 받아야 함 |
| ↓ |  |  |
| 4. 제공 승인 획득 | 개인정보<br>보호책임자 | - 개인정보 보호책임자로부터 목적 외 이용‧제공 승인 절차 진행 |
| ↓ |  |  |
| 5. 목적 외 이용‧제공 | 개인정보취급자 | - 개인정보 보호책임자 승인 후 개인정보 목적 외 이용‧제3자 제공 처리<br>- 개인정보 보호책임자 미승인 시 요청자에게 제공 불가 사유 통보 |
| ↓ |  |  |
| 6.대장 기록‧관리 | 개인정보취급자 | - [개인정보의 목적 외 이용 및 제3자 제공 대장]을 기록‧관리하여야 함<br>- [참고] 개인정보의 목적 외 이용 및 제3자 제공 대장<br>(개인정보 처리방법에 대한 고시 별지 제1호 서식) |
| ↓ |  |  |
| 7. 보호조치 요구 | 개인정보취급자 | - 제3자 제공시에는 이용목적, 이용방법, 이용기간, 이용형태 등을 제한하거나, 개인정보의 안전성 확보를 위하여 필요한 조치(5. 안전성 확보 조치 참조)를 마련하도록 문서로 요청 |
| ↓ |  |  |
| 8. 조치결과 제출 | 개인정보<br>제공요청자 | - 안전성 확보 조치 요청을 받은 자는 그에 따른 조치를 취한 후, 그 결과를 개인정보를 제공한 기관에게 문서로 알려야 함 |
| ↓ |  |  |
| 9. 주요 내용 공개 | 개인정보취급자 | - 목적 외 이용 등을 한 날로부터 30일 이내에 인터넷 홈페이지에 10일 이상 계속 게재<br>- 정보주체의 동의를 받았거나, 범죄의 수사와 공소의 제기 및 유지를 위하여 제공한 경우는 공개하지 않음 |
