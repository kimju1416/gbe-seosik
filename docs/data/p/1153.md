예를 들어 서류상별거시작일: 2014.08.01. 계산기준일:2015.02.28.의 경우

별거기간은 ▶계산식: 계산기준일-서류상별거시작일+1 에 의해

2015.02.28. - 2014.08.01. + 1 = 212일이며 212일은 212/30.4=6.9736…이므로

6개월이고, 212일-(6개월\*30.4=182.4일)=29.6일(≒29일)이므로 00.06.29가 된다.

예를 들어 서류상별거시작일: 2011.03.01. 계산기준일:2015.02.28.의 경우

계산식에 의해 별거기간은 04.00.01이 나오는데 1일이 더 나오는 이유는

윤년(2월29일)에 의해 일->년월일로 환산시 1일이 더 나오게 된다.

(※일자(Day)로 계산한 후 연도는 365일, 월은 30.4일 기준으로 환산하여 yy.mm.dd(년.월.일)로 표시하며, 계산식에 +1를 하는 이유는 양쪽 날짜를 모두 포함하기 위함)
