### □ 업무 절차 (메뉴: 계약직교원-계약직인사기록-계약직교원 자료전송)

○ (요청) 현 근무지: 대상자 등록 → 퇴직교원 찾기 → 저장 → 요청

※ 전 근무지가 타시도인 경우: 등록(타시도) → 총괄서버퇴직교원 찾기 → 저장 → 요청

○ (전송) 전 근무지: 요청받은 대상자 조회 → 전송

○ (확인) 현 근무지: 계약직교원-계약직인사기록-인사기록(계약직)에서 내용 확인
