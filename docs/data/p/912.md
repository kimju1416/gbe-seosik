**1. 교과목변경 조회**
1) 조회조건을 입력하고 조회버튼을 클릭하면
교과목변경 목록이 조회된다.
2) 추가 버튼을 클릭하여 교과목변경을 추가할 수
있다.
- 대상자 버튼을 클릭하면 소속기관의 발령
대상자목록이 조회된다.
- 교과목변경 관련 필수 항목을 입력하고 저장
버튼을 클릭하여 해당 내용을 저장한다.
3) 삭제 버튼을 클릭하여 선택한 목록을 삭제할
수 있다.
4) 출력 버튼을 클릭하면 교과목변경 현황 팝업이
보여지고, 출력양식으로 조회된다.
