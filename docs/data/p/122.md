# 방과후 특성화프로그램 희망 신청서

〔이미지〕

본원에서는 유아의 발달에 적합한 다양한 교육활동으로 학부모님의 만족도 제고 및 사교육비 부담을 경감하는 취지에서『유치원 방과후 특성화프로그램』을 운영하고자 합니다.

202○년 유치원운영위원회 결과 다음과 같은 특성화프로그램을 실시하고자 하오니 참여를 희망하는 경우 00월 00일(○요일)까지 유치원으로 신청서를 보내주시기 바랍니다.

※ 방과후 특성화프로그램은 유아 1인당 주 3개 이내로 선택할 수 있습니다.
