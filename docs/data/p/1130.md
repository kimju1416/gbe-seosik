1. 2023 현원, 2024 배정기준에는 전문상담, 보건, 영양, 사서, 특수교사, 방통중․고를 포함시킬 것

2. 내신가능 인원수는 2023 현원의 1/3이내(소수아래 버림, 교사 정원이 10명 미만인 학교는 올림)

3. 내신자 수 중 (전보)＋(전보전과)의 수가 내신가능인원수 이하이어야 함

4. ‘전보’란의 내신자 수는 전보유예, 초빙관련자, 비정기전보(TO감 포함), 도내 파견기관 근무 만기자, 전과 교사 수는 제외하고 기록하며, 중학교의 경우 관내 전보 내신자 수도 포함(교육지원청은 관내 전보 내신자수 제외하고 기록함) ※단, 정원조정, 비정기전보, 타학교로 초빙된 교사라도 학교근무기간만기(학교만기, 시군만기, 초빙만기, 초빙해지, 사서교사근무만기 등) 교사는 전보내신자수에 포함

5. 학교의 ‘TO감 내역’란은 정원(배정기준) 내의 ‘감’을 말하며, ( ) 안에는 TO감 전체 인원수를 기록하고, 상세내역에는 ‘국어1명, 수학1명’과 같이 과목과 과목별 인원수를 기록

교육지원청의 ‘TO감 내역’란은 관내 중학교의 결원과 TO감을 상쇄한 결과를 기록함

6. ‘증원 내역’란은 정원(배정기준) 내의 ‘증’을 말하며, 작성 방법은 ‘TO감 내역’란과 같음

※ 학교에 배치하는 정원(배정기준) 외에 추가로 교사 증원 요청할 경우 <서식 2>에는 나타내지 않으며, <서식 13>에 의해 별도 요청자료 작성 후 제출
