# 경상북도교육청 서식 꾸러미

경상북도교육청 [학교지원종합자료실](https://www.gbe.kr/edupia/main.do)에 공개된 업무 서식 1,175종을
분류별로 찾아보고, **내려받기 전에 본문을 미리 확인**할 수 있게 만든 단일 페이지 웹앱입니다.

## 기능

- 업무 영역 7종 → 분야 → 업무 3단계 분류 탐색
- 서식 이름·문서번호·업무명 통합 검색
- hwp·hwpx·pdf·xlsx 본문 미리보기 (표 포함)
- 즐겨찾기(브라우저에 저장), 주소 공유용 링크
- 내려받기는 경상북도교육청 원본 서버로 직접 연결

## 데이터

- 수집일: 2026-07-22 · 출처: 경상북도교육청 학교지원종합자료실
- 미리보기 본문은 [kordoc](https://www.npmjs.com/package/kordoc)으로 추출한 텍스트이며,
  글꼴·여백 등 조판은 반영되지 않습니다. 실제 서식은 내려받아 확인하세요.
- 서식 파일 자체는 이 저장소에 포함하지 않습니다. 원본이 교체·삭제되면 내려받기가 동작하지 않을 수 있습니다.

## 구조

```
docs/
  index.html        웹앱 (단일 파일)
  data/index.json   분류·목록 인덱스
  data/p/{id}.md    서식별 미리보기 본문
```
